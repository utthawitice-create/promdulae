# พร้อมดูแล

เว็บแอปพลิเคชันสำหรับโปรแกรมส่งเสริมการรับรู้สมรรถนะแห่งตนของญาติผู้ดูแลผู้ป่วยโรคหลอดเลือดสมองระยะเฉียบพลัน
หอผู้ป่วยวิกฤตโรคหลอดเลือดสมอง โรงพยาบาลนครพิงค์

- `index.html` — ตัวแอป (ไฟล์เดียว ทำงานในเบราว์เซอร์ เก็บข้อมูลในเครื่องของผู้ใช้)
- `img/` — ภาพหน้าปกและภาพสรุปรายบท
- `apps-script-Code.gs` — สคริปต์รับข้อมูลเข้า Google Sheets (ไม่บังคับ)
